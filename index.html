Online archive (GitHub)

Read this before pasting a token. Use a fine-grained token limited to this one repository, with Contents: read and write and nothing else. It's stored in this browser only, is never written into exported files, and is never sent anywhere except github.com. Anyone who unlocks this phone can reach that one repo. Reading a public repo needs no token at all — but a public repo means your site photos and client names are readable by anyone, so a private repo is the right choice for construction administration records.
